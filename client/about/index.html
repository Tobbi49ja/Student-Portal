About Us

The Student Management System is a lightweight, web-based platform designed to streamline student and administrative tasks. Built with a focus on simplicity and accessibility, it serves students and admins by providing an intuitive interface to manage profiles, courses, and records—all without relying on heavy frameworks.

What It Serves

  • For Students: View and edit personal details, change passwords, upload profile pictures, and manage course enrollments with progress tracking.
  • For Admins: Oversee student data with a responsive dashboard, edit records, and delete entries, optimized for mobile with scrollable or collapsible lists.
  • For All: A responsive design that adapts to any screen size, ensuring a seamless experience from desktops to mobile devices.

Our Approach

This project leverages pure HTML, CSS, and JavaScript, styled with a custom Tailwind-inspired design (e.g., `var(--primary): #6366f1`). It uses a Node.js backend with MongoDB for data storage and JWT for secure authentication. The focus is on performance and maintainability, with features like collapsible sections on mobile screens below 768px and progress bars for course tracking.

Vision

Our goal is to provide a scalable, user-friendly tool for educational institutions. Future enhancements may include real-time updates, advanced analytics, and multi-language support, all while keeping the design lightweight and responsive.
